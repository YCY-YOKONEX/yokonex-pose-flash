# 役次元 · 姿势快闪

这是役次元的单人姿势挑战游戏。玩家面对手机摄像头，按画面提示完成动作，在限定时间内保持目标姿势；连接役次元 EMS 设备后，挑战失败会触发设备惩罚。

项目面向玩家、开发者及对互动游戏感兴趣的同行，欢迎交流玩法与开发建议。

## 玩法

### 姿势快闪 · 单人挑战

将手机放稳，让身体进入摄像头画面。每轮准备倒计时结束后，按照目标图示完成动作，并持续保持至判定成功。画面会显示实时骨架和保持进度，整局结束后汇总成功与失败轮数。

目标动作随机出现，涵盖举手、平举、抱头、半蹲、单腿抬起等姿势。非对称动作支持左右镜像完成，相邻轮次的起始动作不会重复。

### 连续动作 · 递进挑战

可在开始前调整挑战轮数和每轮时间。较长局数的挑战会逐步缩短作答时间，并在后半程加入连续动作；玩家需要依次完成并保持每个动作，才能通过该轮。

### 设备联动 · 失败惩罚

支持连接役次元一代、二代 EMS 设备。超时未完成动作时，游戏触发设备惩罚，结束后进入下一轮。惩罚强度根据首次失败强度和递增设置，随失败次数增加，达到上限后保持不变。

开始前可在独立设备页面完成蓝牙连接。设备未连接或指令发送失败时，挑战流程仍可继续。

## 体验说明

- 保持身体在摄像头可识别范围内；上半身出画或识别结果不可用时，挑战暂停计时。
- 切换到后台后游戏自动暂停，返回后可手动继续。
- 姿势识别在手机本地完成，摄像头画面不录像、不保存、不上传，运行时无需下载姿势模型。
- 使用 EMS 设备前，应按设备说明确认佩戴方式和适用条件，从低强度开始体验。

## 参与交流

欢迎反馈实际体验中的动作识别问题，或提出新的姿势、挑战规则和设备互动建议。反馈时可说明手机型号、出现问题的动作及操作过程，便于复现和改进。

## 开始体验

项目基于 Flutter，包含 Android 和 iOS 工程，目前可通过源码在手机上运行。

准备好 Flutter 开发环境并连接手机后，在项目目录执行：

```sh
flutter pub get
flutter run
```

iOS 运行需要 macOS、Xcode 和 CocoaPods，并在 Xcode 中配置开发团队与签名。
